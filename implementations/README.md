# Versioned implementation baselines

This directory contains source extracted from the immutable release archives in archives/.

- semantic-workbench-js/v0.5.4/: JavaScript/browser Semantic Workbench v0.5.4.
- python-kernel/v0.4.0/: Python reference system/kernel v0.4.0.

These are separate implementations with independent versioning, runtimes, tests, and internal representations. Their co-location does not imply integration or semantic interoperability. The original ZIP archives remain preserved under archives/.
