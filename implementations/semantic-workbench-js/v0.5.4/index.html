ACTIVE RULE SET
Rules the engine can apply
2 RULES
R-IS-A-TRANSITIVE
Subclass transitivity
If A is a subclass of B, and B is a subclass of C, then A is a subclass of C.
SUBCLASS_OF(A, B) ∧ SUBCLASS_OF(B, C) → SUBCLASS_OF(A, C)
R-INSTANCE-INHERITANCE
Instance inheritance
If X is an instance of A, and A is a subclass of B, then X is an instance of B.
INSTANCE_OF(X, A) ∧ SUBCLASS_OF(A, B) → INSTANCE_OF(X, B)
These are deliberately small demonstration rules. The engine does not have general common-sense reasoning.

i
What the local model does—and does not do
The LLM proposes semantic interpretations. USG validates the response shape, records source evidence, and keeps proposed claims separate until you accept them. This does not guarantee that the interpretation is correct. The small symbolic reasoning engine remains independent of the model.
