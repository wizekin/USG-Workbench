# USG Interpretation Gold Benchmark v0.4.0

Candidate benchmark for Phase 6 Step 6.6. It contains 500 fixtures across ten English/MSA Arabic nominal and modifier profiles: adjective modification, possession, noun compounds, prepositional nominal modification, and temporal/adverbial modification. Each profile has 20 positive, 20 negative, and 10 ambiguous fixtures. All constructions remain disabled; this is not evidence of runtime support or parser accuracy.

Offsets are Unicode code points. Predicate spans and grammatical markers are separate from participant/head/modifier role spans. v0.3.0–v0.3.2 remain immutable.
