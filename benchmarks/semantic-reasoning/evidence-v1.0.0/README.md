# Evidence Assessment Benchmark 1.0.0

This benchmark is additive and separate from the frozen Step 2.2 semantic
reasoning corpus and the Step 2.6 executor fixtures. Every case contains a
complete canonical USG-SEM/1.0 document and an explicit assessment task.

Coverage includes exact, mismatched, Unicode-offset, hash-mismatched, and
unresolved source spans; declared support labels that must not be promoted;
unverified CONTRADICTS relation labels; exact same-scope opposite-polarity
conflicts; context and attribution boundaries; multiple source records without
established independence; shared-lineage sources; and external verification
declarations that remain unverified.

The benchmark requires independent result axes. Quote alignment is not
semantic support, relation labels are not proof, distinct source IDs are not
corroboration, and declared verification is not verified truth.
