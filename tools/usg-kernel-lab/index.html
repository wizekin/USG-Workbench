USG Kernel Lab

USG means Universal Semantic Grammar — explore how it reads and organizes text

Runs on this computer

Welcome — you do not need a programming background

Type a sentence, choose a language, and select an analysis button. The tables will explain what USG noticed in everyday English.

USG is an experimental system. It can recognize only some language patterns, so it may miss meanings, misunderstand a sentence, or leave parts unanswered. A result means “this is what the current system found,” not “this is definitely true.”

Your information stays here: this lab runs on your computer. It does not upload your text to a cloud service.

2 · Look more closely

See the detailed reading, step by step

More analysis stages

This version examines the text in several stages. It may identify words, split the text into sentence parts, notice grammar-like patterns, combine possible meanings, and suggest what later words may refer to. Each result is a possibility unless it is clearly marked as confirmed by a specific rule.

Ready when you are.
Your detailed result will appear here after you select “Analyze in more detail.”

3 · Try a prepared example

Ask USG a question about information it already knows

Rule-based reasoning

Choose an example prepared for this system. USG will use the example's stored facts and rules to see whether it can support the requested conclusion. This section does not accept a question written in ordinary language.

The examples are test cases, not a measure of how well USG understands every kind of question.

Choose a prepared example and select “Run this example” to see the result.
Advanced question settings (optional)
